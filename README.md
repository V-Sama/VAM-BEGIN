## ✨ 功能一览

- 🎮 **一键启动游戏** — 支持桌面模式 / VR 模式 (OpenVR)
- 📋 **选择 Var 包** — 浏览资源包、预览图展示、自动解析依赖、按需加载
- 📦 **迁移 Var 包** — 从游戏目录批量迁移到本地管理路径
- 🔍 **解析 Var 包** — 提取预览图并缓存，加速后续浏览
- 📂 **整理 Var 包** — 按作者归类、智能去重、清理冗余文件
- ♻ **回收站** — 管理整理后产生的重复/无效文件
- 🎨 **个性化** — 浅色/深色/跟随系统主题，自定义壁纸

## 🚀 快速开始

### 环境要求

- Windows 10 / 11
- [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

### 安装与使用

1. 从 [Releases](../../releases) 下载最新版本
2. 解压后运行 `VamBegin.exe`
3. 点击左上角箭头按钮打开侧边栏，进入 **设置 → 路径**
4. 配置以下路径：
   - **游戏安装路径** — Virt-A-Mate 游戏根目录
   - **本地 Var 包路径** — 存放 `.var` 资源包的目录（不设置则使用程序目录下的 AddonPackages）

### 推荐流程

```
设置路径 → 迁移 Var 包 → 解析 Var 包 → 整理 Var 包 → 选择 Var 包 → 启动游戏
```

## 📖 功能详解

### 🎮 首页 · 启动游戏

提供 **桌面模式** 和 **VR 模式** 两个启动按钮，点击即可启动 Virt-A-Mate。

> 💡 点击首页的 "VAM-BEGIN" 标题可以随机切换壁纸 🎲

### 📋 选择 Var 包

核心功能，实现 **按需加载**：

- 浏览本地所有 `.var` 资源包，支持预览图和搜索
- 勾选需要的资源包后，程序自动分析依赖关系
- 将选中的包及其依赖复制到游戏目录，游戏只加载你需要的资源
- 默认开启「仅添加」模式 — 增量复制，不清除已有资源

### 📦 迁移 Var 包

将游戏目录 `AddonPackages` 下的 `.var` 文件批量迁移（剪切）到本地 Var 包路径。释放游戏目录空间，配合「选择 Var 包」实现按需加载。

### 🔍 解析 Var 包

扫描本地 `.var` 文件，提取预览图并建立缓存。首次使用前建议先执行一次解析，后续浏览将直接从缓存加载，大幅提升速度。

### 📂 整理 Var 包

对本地 Var 包目录进行自动整理：

| 操作 | 说明 |
|------|------|
| 按作者归类 | 自动创建作者子目录，将文件归入对应文件夹 |
| 智能去重 | 保留最新版本，旧版本移入回收站 |
| 非标准文件 | 命名不规范的文件移入 Others 目录 |
| 清理冗余 | 删除 `.txt` / `.url` 文件，清理空文件夹 |

整理完成后自动生成日志文件，记录所有操作详情。

### ♻ 回收站

管理「整理 Var 包」产生的重复/无效文件：
- 查看文件列表和占用空间
- 支持勾选删除或一键清空

### ⚙ 设置

| 设置项 | 说明 |
|--------|------|
| 📂 路径 | 配置游戏安装路径和本地 Var 包路径，修改后自动保存 |
| 🖼 壁纸 | 管理背景壁纸列表，支持添加自定义图片，启动时随机展示 |
| 🎨 主题 | 浅色 / 深色 / 跟随系统 三种模式 |

## ❓ 常见问题

**Q: 启动时提示"游戏路径未配置"？**
> 打开侧边栏 → 设置 → 路径，配置 Virt-A-Mate 游戏的根目录。

**Q: 选择 Var 包后游戏里看不到资源？**
> 确保游戏目录 `AddonPackages` 根目录下没有散落的 `.var` 文件。如果有，建议先使用「迁移 Var 包」功能将它们迁移到本地路径。

**Q: 预览图加载很慢？**
> 首次使用前先执行一次「解析 Var 包」，建立预览图缓存后浏览速度会大幅提升。

**Q: 整理后文件丢失了？**
> 整理操作不会直接删除任何 `.var` 文件，去重的文件会移入回收站（`VAMB_RecycleStation` 目录），可随时查看和恢复。
