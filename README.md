## ✨ 功能一览

- 🎮 **一键启动游戏** — 支持桌面模式 / VR 模式 (OpenVR)
- 🖱 **拖拽导入** — .var 文件或整个文件夹拖进窗口：自动去重入资源库，随后询问是否同步到游戏库
- 🔎 **自动收编** — 启动时嗅探游戏目录中散落的未入库资源，自动移动入库并同步回游戏库，游戏目录不再有"漏网之鱼"
- 📋 **资源库工作台** — 预览图浏览、搜索、分类筛选、排序、⭐ 收藏 / 🕒 最近使用 / 🏷 自定义标签；「全选筛选结果」批量勾选；绿色「已同步」角标标记已在游戏库中的资源
- 🗑 **一键卸载** — 资源库右键或批量卸载：从游戏移除（本地库副本保留），删除前展示依赖预览、自动处理孤儿依赖
- 🌲 **依赖可视化** — 卸载/删除前展示依赖树预览，本地缺失依赖红色标记
- 🧩 **预设依赖管理** — 场景/外观预设的依赖分析，卡片红色「缺 N」徽章、右键补齐单个预设、一键补齐全部到 CustomDp
- 📦 **包详情页** — 描述 / 许可 / 依赖缺失 / 内容列表一目了然
- 📦 **库间迁移** — 游戏目录与本地库双向迁移，同名文件自动跳过
- 🔍 **解析 Var 包** — 提取预览图并缓存，加速后续浏览
- 📂 **整理 Var 包** — 按作者归类、智能去重、垃圾文件移入回收站（整理前预览、完成后报告卡片）
- ♻ **回收站** — 保留期设置（7/30/90 天）、过期一键清理、选择性删除
- 💾 **一键备份 / 导出依赖清单** — 配置备份 + 依赖清单（含本地缺失标记），可导出分享
- 📊 **空间统计** — 扇形图占比（本地库/回收站/游戏目录）+ 明细与作者 Top3
- 🧹 **预览缓存面板** — 占用/上限展示，一键清理
- 🔄 **检查更新** — 一键检查 GitHub 新版本并跳转下载
- 🎨 **个性化** — 浅色/深色/跟随系统主题，自定义壁纸

## 🚀 快速开始

### 环境要求

- Windows 10 / 11
- [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

### 安装与使用

1. 从 [Releases](../../releases) 下载最新版本
2. 解压后运行 `VamBegin.exe`
3. 点击左上角箭头按钮打开侧边栏，进入 **设置 → 常规设置**
4. 配置以下路径：
   - **游戏安装路径** — Virt-A-Mate 游戏根目录
   - **本地 Var 包路径** — 存放 .var 资源包的目录（不设置则使用程序目录下的 AddonPackages）

### 推荐流程

```
最简用法：设置路径 → 拖入 .var（或文件夹）→ 确认同步到游戏库 → 启动游戏
日常管理：资源库勾选 → 「仅同步」/「启动游戏」；「恢复上次选择」记住上次勾选
大库管理：库间迁移 → 解析 Var 包 → 整理 Var 包 → 回收站
```

> 💡 无论资源以何种方式进入游戏库（拖拽导入 / 手动放入），都会被自动收编进本地库统一管理；启动时自动补齐预设依赖。

## 📖 功能详解

### 🎮 首页 · 启动游戏

提供 **桌面模式** 和 **VR 模式** 两个启动按钮，点击即可启动 Virt-A-Mate。

> 💡 点击首页的 "VAM-BEGIN" 标题可以随机切换壁纸 🎲
> 💡 直接把 .var 文件拖进窗口即可导入本地库。

### 🖱 拖拽导入

- 从资源管理器把 **.var 文件或整个文件夹**拖进主窗口（文件夹自动递归扫描其中所有 .var）
- 先**去重入资源库**并后台重建预览图，随后弹窗询问**是否同步到游戏库**
- 同意后走与「仅同步」相同的管线：选中包 → MainPak、依赖 → Dp，本局即可用
- 同名文件自动跳过，导入结果实时显示；多文件夹重叠自动去重

### 🔎 自动收编

每次启动游戏时嗅探游戏目录：

- 发现游戏目录中有、但本地库没有的 .var → 提示「发现散落资源」
- 选「是」：**移动入库**（游戏目录清理干净），随后自动同步回游戏库（选中→MainPak、依赖→Dp）
- 选「否」：保留在游戏并登记为最近使用（30 天内不重复提示）

### 📋 资源库工作台

核心页面，实现 **按需加载**：

- 浏览本地所有 .var 资源包，支持预览图、搜索、分类筛选、排序（名称/大小/加入时间，偏好记忆）
- ⭐ 收藏 / 🕒 最近使用（30 天内）过滤，🏷 自定义标签
- 绿色「**已同步**」角标标记已在游戏库中的资源，同步/卸载后即时刷新
- 「全选筛选结果」批量勾选当前筛选（跨搜索/标签累加），「取消全选」一键清空
- 右键卡片：收藏 / 添加自定义标签 / 查看详情 / 在 Hub 搜索 / 打开所在文件夹 / 卸载（从游戏移除）
- 勾选需要的资源包后，程序自动分析依赖关系并复制到游戏目录
- 默认开启「仅添加」模式 — 增量复制，不清除已有资源

### 🗑 卸载

资源库中右键「卸载（从游戏移除）」或底部「卸载所选」批量卸载：

- 卸载前展示依赖树预览，本地缺失的依赖红色标记
- 从游戏目录移除选中包及其**孤儿依赖**（仅被选中包引用的依赖）
- **本地库副本始终保留**，想再装只需重新勾选「仅同步」
- 游戏目录中没有该文件时自动跳过并提示

### 🧩 预设依赖管理

- 扫描场景（.json）与外观（.vap）预设所引用的 var 包
- 卡片红色「**缺 N**」徽章标出缺失依赖数
- 右键预设：「查看详情」（依赖列表缺失标红）或「补齐此预设依赖」
- 「补齐全部依赖」一键把本地库可解析的依赖复制到 CustomDp
- 启动游戏时自动补齐（可在设置中关闭），引用解析结果带持久化缓存，二次启动秒级完成

### 📦 包详情页

右键「查看详情」查看单个包的完整信息：描述、许可、依赖列表（缺失标红）、内容文件。

### 📦 库间迁移

游戏目录与本地库**双向迁移**：

- 「迁移到本地」— 把游戏目录 `AddonPackages` 下的 .var 移动（剪切）到本地库，释放游戏目录空间；本地已有同名时游戏副本移入回收站
- 「回迁到游戏」— 把本地库文件移回游戏目录，同名文件自动跳过

配合「资源库工作台」实现按需加载。

### 🔍 解析 Var 包

扫描本地 .var 文件，提取预览图并建立缓存。首次使用前建议先执行一次解析，后续浏览将直接从缓存加载，大幅提升速度。

### 📂 整理 Var 包

对本地 Var 包目录进行自动整理：

| 操作 | 说明 |
|------|------|
| 按作者归类 | 自动创建作者子目录，将文件归入对应文件夹 |
| 智能去重 | 保留最新版本，旧版本移入回收站 |
| 非标准文件 | 命名不规范的文件移入 Others 目录 |
| 清理冗余 | .txt / .url 移入回收站（可恢复），清理空文件夹 |

整理前会预览待回收文件，完成后弹出报告卡片（统计 + 错误明细 + 打开日志）。

### ♻ 回收站

管理「整理 Var 包」产生的重复/无效文件：

- 查看文件列表和占用空间
- 保留期设置：永久 / 7 / 30 / 90 天（设置 → 常规设置）
- 一键清理超过保留期的文件
- 支持勾选删除或一键清空

### 💾 备份与导出

- **一键备份**：程序配置 + 依赖清单（含本地缺失标记）打包到带时间戳目录，实时进度
- **导出依赖清单**：生成 `依赖清单.md`，可直接分享给他人对照补依赖

### 📊 空间统计

本地库 / 回收站 / 游戏目录的包数与占用以扇形图直观展示（悬停显示百分比），并列出作者占用 Top3 与可回收空间。

### 🧹 预览缓存

显示预览图缓存占用与上限（默认 500MB，超限自动淘汰最旧文件），支持一键清理。

### 🔄 检查更新

设置 → 常规设置页点击「检查更新」，自动比对 GitHub 最新版本，一键跳转下载页。

### ⚙ 设置

| 设置项 | 说明 |
|--------|------|
| 📂 路径 | 配置游戏安装路径和本地 Var 包路径，修改后自动保存 |
| ♻ 回收站保留期 | 永久 / 7 / 30 / 90 天 |
| 🔄 版本与更新 | 检查新版本并跳转下载页 |
| 🖼 壁纸 | 管理背景壁纸列表，支持添加自定义图片，启动时随机展示 |
| 🎨 主题 | 浅色 / 深色 / 跟随系统 三种模式 |
| 🚀 启动行为 | 启动前自动补齐预设依赖到 CustomDp；游戏目录散落资源的自动收编提示 |

## ❓ 常见问题

**Q: 启动时提示"游戏路径未配置"？**
> 打开侧边栏 → 设置 → 常规设置，配置 Virt-A-Mate 游戏的根目录。

**Q: 选择 Var 包后游戏里看不到资源？**
> 同步会把资源复制到 `AddonPackages\MainPak`（依赖在 `Dp`）。如果游戏仍看不到，检查 `AddonPackages` 根目录下是否有散落的 .var 文件——下次启动时会自动收编入库；也可以手动使用「库间迁移 → 迁移到本地」清理。

**Q: 预览图加载很慢？**
> 首次使用前先执行一次「解析 Var 包」，建立预览图缓存后浏览速度会大幅提升。

**Q: 整理后文件丢失了？**
> 整理操作不会直接删除任何 .var 文件，去重/冗余文件会移入回收站（`VAMB_RecycleStation` 目录），可随时查看和恢复。可在设置中配置回收站保留期。

**Q: 如何备份配置和依赖清单？**
> 资源管理页 →「一键备份」（配置 + 依赖清单打包）或「导出依赖清单」（单独生成 `依赖清单.md`）。

**Q: 如何检查新版本？**
> 设置 → 常规设置页 →「检查更新」，会自动比对 GitHub 最新 Release 并跳转下载页。
